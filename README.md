# Neuron

Neural networks from scratch in C, built on a small matrix multiplication library.

## Goals

- Neural networks built from scratch: neurons, layers, activation functions and backpropagation, with no machine learning libraries.
- Start with the logic gates (AND, OR, NAND, NOR, XOR, XNOR), then possibly one or more harder networks.
- A small matrix multiplication library: recursive divide and conquer with a base-case threshold, parallelized with OpenMP tasks.
- Tested, and benchmarked with a simple benchmark of my own. No comparison with other matrix libraries.

## Status

Early development. Nothing usable yet.
